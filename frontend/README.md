# Frontend — контрольная точка 2

Реализованы F1 и F2 по контракту: POST /api/chat, источники, отдельный отказ no_context, ошибки и ожидание; экран Benchmark с запуском, опросом статуса, метриками и таблицей. Обновлены документы интерфейса и сценариев (F3). Демо-вход admin/admin сохранён; настоящей авторизации нет.

## Посмотреть

Из корня проекта:

```bash
python3 -m http.server 5500 --directory frontend
```

Открыть http://localhost:5500, войти admin/admin. Слева Benchmark → «Показать пример». Это явно обозначенные демонстрационные данные, а не результаты RAG.

Для реального чата и запуска benchmark нужен backend Сейрана на http://localhost:8000. Адрес меняется в первой строке script.js, константа API_URL. Backend должен разрешать CORS для http://localhost:5500. Не открывать index.html через file://.
