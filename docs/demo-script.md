# Сценарий показа первой точки

План на 5–7 минут.

1. **Frontend (около минуты).** Тема и пользователь: «Студенту нужно быстро найти требование в методичке и проверить ответ по источнику».
2. **Frontend (1–2 минуты).** Открыть прототип, войти `admin/admin`, показать подсказки, отправить вопрос из S01, показать историю, удаление диалога и мобильную ширину. Прямо сказать: «Сейчас ответ демонстрационный, поиск и модель подключаются следующим этапом».
3. **Backend (1–2 минуты).** Схема архитектуры, контракт `POST /api/chat`, точка подключения `askAssistant()`, структура репозитория, ветки и Pull Request, проверка документации в GitHub Actions.
4. **RAG (1–2 минуты).** Какие документы кафедры собираем, как режем на фрагменты с номерами страниц, лемматизация, BM25, методика benchmark и эксперименты E1–E4. Подчеркнуть, что метрик ещё нет.
5. **Все.** План и распределение работы; каждый может объяснить общий путь запроса.

## Подготовка

Проверить запуск по README на ноутбуке для показа заранее. Держать скриншоты из `docs/images/` как запасной вариант.

## Вопросы, к которым команда готова

- Почему BM25, а не сразу векторный поиск?
- Как русская морфология влияет на BM25 и как это проверим?
- Что будет, если в методичках нет ответа?
- Как студент проверит, что ответ не выдуман?
- Почему модель локальная, а не через внешний API?
- Что реально готово сейчас и что будет на следующей точке?
