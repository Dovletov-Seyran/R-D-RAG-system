# Первая контрольная точка

## Что нужно показать

Тема и пользователь, основной сценарий, документация, интерфейс, структура репозитория и распределение работы. Работающий RAG на этой точке не требуется.

## Где это в репозитории

| Требование | Где смотреть | Чем подтвердить |
| --- | --- | --- |
| Тема и пользователь | [README](../README.md), [product](../spec/product/product.md) | Объяснить задачу студента ИУ-5 |
| Основной сценарий | [scenarios](../spec/product/scenarios.md) S01, [demo-script](demo-script.md) | Пройти вход, вопрос, ответ |
| Документация | [spec/product](../spec/product/), [spec/tech](../spec/tech/) | Показать архитектуру, API, RAG, методику проверки |
| Интерфейс | [frontend/](../frontend/) | Открыть в браузере, честно назвать демо-ответ |
| Структура репозитория | [repository-structure](repository-structure.md) | Показать дерево в GitHub |
| Распределение работы | [team](../spec/team.md), [plan](../spec/plan.md) | Каждый объясняет свою роль |
| README и запуск | [README](../README.md#запуск-прототипа) | Коллега запускает по инструкции |
| История изменений | Git-коммиты, Pull Request, [CHANGE_HISTORY](../CHANGE_HISTORY.md) | Показать историю в GitHub |
