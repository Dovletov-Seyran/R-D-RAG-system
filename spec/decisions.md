# Журнал решений

| ID | Решение | Основание | Ограничение |
| --- | --- | --- | --- |
| D01 | BM25 как первый метод поиска | Требование курса; работает на CPU, легко объяснить | Чувствителен к формулировке вопроса |
| D02 | Лемматизация русского текста (pymorphy3) | Методички и вопросы на русском, много словоформ | Ошибки разбора редких терминов и сокращений |
| D03 | Python + FastAPI для backend и поиска | Один язык для API, индексатора и экспериментов | Производительность не критична для учебной нагрузки |
| D04 | Поиск — модуль внутри backend на первом этапе | Маленькая команда, меньше сервисов для запуска | При росте может понадобиться отдельный сервис |
| D05 | Локальная LLM через Ollama | Материалы кафедры не уходят во внешние API, нет платных ключей | Нужен компьютер с достаточной памятью или GPU |
| D06 | Статический frontend без сборки на точке 1 | Быстрый показ интерфейса без зависимостей | Нет компонентов и типизации; пересмотреть при росте |
| D07 | История диалогов в `localStorage` | Не нужна БД для MVP | История не переносится между устройствами |
| D08 | Источник = документ + страница из metadata | Студент может открыть методичку и проверить | Требует сохранять номера страниц при извлечении |
| D09 | `main` + короткие ветки задач + Pull Request | Три участника, частая интеграция | Требует регулярного review |

Смена решения записывается новой строкой с причиной и влиянием на API и проверки.
