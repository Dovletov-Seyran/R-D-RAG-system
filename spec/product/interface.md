# Интерфейс

## Экраны

| Экран | Состав |
| --- | --- |
| Вход | Шапка с логотипом кафедры, описание ассистента, форма логина и пароля, ошибка входа |
| Чат | Боковая панель (новый диалог, история, ссылка на сайт кафедры, пользователь и выход), заголовок диалога со статусом базы знаний, область сообщений, поле ввода |
| Новый диалог | Приветствие и три карточки-подсказки: «Объяснить тему», «Подготовка к защите», «Найти в материалах» |

Скриншоты — [docs/images](../../docs/images/).

## Сообщения

- Сообщение студента — справа, подпись «ВЫ».
- Ответ ассистента — слева, подпись «АССИСТЕНТ ИУ-5», под ответом строка «Источник: …».
- Во время ожидания показывается индикатор из трёх точек.
- Текст выводится через `textContent`, поэтому HTML из ответа модели не исполняется.

## Состояния

Пустая история, новый диалог, ожидание ответа, ответ с источниками, ошибка сервера, ошибка входа. Enter отправляет, Shift+Enter переносит строку, пустое сообщение не отправляется.

## Адаптивность

| Ширина | Поведение |
| --- | --- |
| > 1050 px | Две колонки: боковая панель и чат; подсказки в ряд |
| ≤ 1050 px | Подсказки в столбец |
| ≤ 820 px | Боковая панель выезжает по кнопке ☰, экран входа в одну колонку |
| ≤ 540 px | Уменьшенные шапка, аватары и поле ввода; кнопки шапки скрыты |

## Визуальный стиль

Тёмная тема, акцентный цвет `#4bc9e8`, шрифт Inter. Цвета заданы CSS-переменными в `:root` файла `frontend/styles.css`.

## Подключение backend

Единственная точка подключения — функция `askAssistant(question, chat)` в `frontend/script.js`. Сейчас она возвращает демо-ответ через 750 мс. Контракт будущего запроса — [spec/tech/api.md](../tech/api.md).

## Дальнейшие улучшения

- Markdown в ответах (списки, код) через безопасный рендер.
- Кликабельные источники с показом найденного фрагмента.
