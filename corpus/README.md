# Корпус

Реальные документы кафедры ещё не включены.

## План структуры

```text
corpus/
├── raw/            исходные PDF и DOCX
├── processed/      извлечённый текст по страницам (JSONL)
└── manifest.json   перечень документов
```

## manifest.json

```json
{
  "corpus_version": "2026-11-01",
  "documents": [
    {
      "doc_id": "lab3-guide",
      "title": "Методические указания к ЛР3",
      "discipline": "Название дисциплины",
      "doc_type": "lab_guide",
      "year": 2025,
      "file": "raw/lab3-guide.pdf",
      "sha256": "..."
    }
  ]
}
```

Перед включением документа проверить, что текст извлекается и номера страниц совпадают с оригиналом. Персональные данные студентов в корпус не попадают. Подробнее — [spec/tech/rag.md](../spec/tech/rag.md).
