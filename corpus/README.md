# Корпус

Корпус точки 2 — 30 документов `D01…D30` по материалам 1 курса, 1 семестра: математический анализ, аналитическая геометрия, информатика, основы программирования, начертательная геометрия (решение D11 в [журнале](../spec/decisions.md)).

## Структура

```text
corpus/
├── manifest.json   перечень документов D01…D30 с metadata
├── extract.py      извлечение текста: python -m corpus.extract --source <папка>
└── processed/      извлечённый текст, Dxx.jsonl — одна строка на страницу
```

Исходные PDF и DOCX в Git не коммитятся: они лежат у участника RAG в папке материалов семестра. В репозитории — `manifest.json` и `processed/`, поэтому индекс собирается без исходников.

## manifest.json

| Поле | Описание |
| --- | --- |
| `doc_id` | `D01`…`D30` — ID документа в benchmark |
| `title`, `discipline`, `doc_type` | Название, дисциплина, тип: `lecture`, `guide` (методичка), `exam` (теория и ответы к РК и экзамену) |
| `source` | Путь к исходнику относительно папки материалов (`source_root`) |
| `page_kind` | `page` — номер страницы PDF; `block` — номер блока DOCX (DOCX не хранит страниц, абзацы группируются по ~2500 символов) |
| `pages_total`, `pages_with_text`, `chars` | Объём; страницы без текста (рисунки, пустые) не включаются |
| `sha256` | Хеш исходного файла — по нему видно, что документ изменился |
| `redact` | Фразы с фамилиями, которые удаляются при извлечении |

## Повторное извлечение

```bash
python -m corpus.extract --source "../1 курс/1сем"
python -m search.build
```

Извлечение: PDF постранично через `pypdf`, DOCX по абзацам и таблицам через `python-docx`. Нормализуются пробелы, склеиваются переносы слов, удаляется водяной знак «МГТУ ФН-12» (D09).

## Персональные данные

Отчёты студентов с титульными листами в корпус не взяты. Строки с номером учебной группы (`ИУ5-11Б` и т. п.) удаляются автоматически, отдельные фамилии в благодарностях — через поле `redact` (D05, D08).

Темы документов намеренно пересекаются (лекции, ответы к РК и экзамену по одной дисциплине): на каждый обычный вопрос benchmark в корпусе есть минимум 3 документа с ответом. D06 и D08 — перечни вопросов без ответов: они похожи на нужные документы по словам, но ответа не содержат и проверяют, что поиск не ставит их выше документов с ответом.

## Известные ограничения

- В D02 формулы набраны нестандартным шрифтом и извлекаются как набор символов; русский текст при этом читается.
- Сканы без текстового слоя (рабочие тетради, часть билетов) не включены.
- Подробнее о предобработке и поиске — [spec/tech/rag.md](../spec/tech/rag.md).
