# Benchmark

Размеченный набор вопросов и результаты ещё не созданы. `questions.example.jsonl` — только пример формата (`split: "example"`), он не используется для метрик.

## Формат вопроса

| Поле | Описание |
| --- | --- |
| `id` | Идентификатор вопроса |
| `split` | `dev` — для настройки, `holdout` — для итоговой оценки |
| `query` | Вопрос студента |
| `answerable` | Есть ли ответ в корпусе |
| `gold_doc_ids` | Документы, где есть ответ |
| `gold_pages` | Страницы с ответом |
| `reference_answer` | Эталонный ответ, проверенный человеком |

Метрики и эксперименты — [spec/tech/testing.md](../spec/tech/testing.md).
