## Ответы

**Q01. Что значит, что число является пределом последовательности? Как это записать через эпсилон и номер N?**

Ответ (ok): Число a называется пределом последовательности {xn}, если для любого положительного ε существует номер N = N(ε) такой, что для всех n ≥ N выполняется неравенство |a − xn| < ε. Это записывается как: ∀ε > 0 ∃N = N(ε) ∈ ℕ: ∀n ≥ N, |a − xn| < ε [1].

Эталон: Число a — предел последовательности {xn}, если для любого ε > 0 существует номер N = N(ε) такой, что при всех n ≥ N выполняется |xn − a| < ε. Пишут lim xn = a при n → ∞; последовательность, имеющая предел, называется сходящейся.

**Q02. Что такое наклонная асимптота графика функции и как понять, что она есть?**

Ответ (ok): Наклонная асимптота графика функции — это прямая y = Ax + B, к которой стремится график функции при x → +∞ или x → −∞. Говорят, что функция имеет наклонную асимптоту, если разность между значением функции и уравнением прямой стремится к нулю при x → ±∞.

Чтобы понять, что наклонная асимптота есть, нужно проверить существование двух конечных пределов:
- k = lim x→±∞ f(x)/x,
- b = lim x→±∞ (f(x) − kx).

Если оба предела конечны, то прямая y = kx + b является наклонной асимптотой [5].

Эталон: Прямая y = kx + b — наклонная асимптота графика y = f(x) при x → ±∞, если f(x) = kx + b + α(x), где α(x) — бесконечно малая. Асимптота существует тогда и только тогда, когда существуют конечные пределы k = lim f(x)/x и b = lim (f(x) − kx).

**Q03. О чём говорит теорема Лагранжа о конечных приращениях и какие у неё условия?**

Ответ (ok): Теорема Лагранжа о конечных приращениях гласит: если функция \( f(x) \) непрерывна на отрезке \([a; b]\) и дифференцируема на интервале \((a; b)\), то существует хотя бы одна точка \( c \in (a; b) \), для которой выполняется равенство:

\[
f(b) - f(a) = f'(c)(b - a)
\]

Условия теоремы:  
1. Функция \( f(x) \) непрерывна на \([a; b]\);  
2. Функция \( f(x) \) дифференцируема на \((a; b)\).

Эталон: Если функция f(x) непрерывна на отрезке [a, b] и дифференцируема на интервале (a, b), то найдётся точка c ∈ (a, b), в которой f(b) − f(a) = f′(c)(b − a) — формула конечных приращений.

**Q04. Как по определителю понять, что у матрицы есть обратная, и что такое смешанное произведение векторов?**

Ответ (ok): Чтобы по определителю понять, что у матрицы есть обратная: матрица имеет обратную тогда и только тогда, когда её определитель не равен нулю [2].

Смешанное произведение векторов — это скалярное произведение вектора на векторное произведение двух других векторов, и оно равно определителю третьего порядка, строками которого являются координаты векторов [1].

Эталон: Квадратная матрица A имеет обратную тогда и только тогда, когда det A ≠ 0. Смешанное произведение трёх векторов a, b, c — число (a × b)·c, скалярное произведение векторного произведения первых двух векторов на третий; по модулю оно равно объёму параллелепипеда, построенного на векторах.

**Q06. Как посчитать количество информации в сообщении по формуле Хартли?**

Ответ (ok): Количество информации в сообщении по формуле Хартли рассчитывается по формуле:  
I = n * log₂ m,  
где n — длина сообщения (количество символов), m — размер алфавита.  

Это утверждение подтверждается в фрагменте [4]: «Количество информации, содержащееся в последовательности из n символов из алфавита Am, в соответствии с формулой Хартли равно I = log₂ (mⁿ) = n log₂ m».

Эталон: При структурном подходе количество информации в последовательности из n символов алфавита из m символов по формуле Хартли равно I = log2(m^n) = n·log2 m бит.

**Q07. Как в компьютере хранят отрицательные целые числа и что такое дополнительный код?**

Ответ (ok): Отрицательные целые числа в компьютере хранятся с помощью дополнительного кода. Дополнительный код образуется путём получения обратного кода и добавления к младшему разряду единицы [3]. Для отрицательного числа дополнительный код формируется таким образом, что положительное число имеет такой же прямой код, а отрицательное число — дополнительный код, полученный по указанному правилу [2]. Дополнительный код положительного числа совпадает с его прямым кодом [4]. 

Для целого отрицательного числа в n-разрядном представлении дополнительный код образуется по формуле [A]доп = 10^n + A [5].

Эталон: Целые числа со знаком хранятся в дополнительном коде: старший разряд знаковый (0 — плюс, 1 — минус). Дополнительный код положительного числа совпадает с прямым; для отрицательного числа цифровые разряды инвертируются (обратный код) и к младшему разряду прибавляется 1.

**Q08. Что такое указатель в языке Си и как с его помощью получить доступ к переменной?**

Ответ (ok): Указатель в языке Си — это переменная, содержащая адрес другой переменной, т.е. значением переменной типа указатель является целое число, равное адресу того объекта, на который ссылается указатель [1].  

Чтобы получить доступ к переменной через указатель, используется операция разыменования *имя_указателя, которая позволяет получить значение по адресу, хранящемуся в указателе [4]. Например, если указатель pa указывает на переменную a, то выражение *pa даст значение переменной a, а *pa = новое_значение изменит значение переменной a [4].

Эталон: Указатель — переменная (объект), значением которой является адрес другого объекта или функции. Объявляется с символом *, адрес переменной получают операцией &, а значение по адресу — разыменованием через *.

**Q09. Что такое рекурсия в программировании и какой бывает рекурсивная функция?**

Ответ (ok): Рекурсия в программировании — это ситуация, когда функция вызывает саму себя. Такая функция называется рекурсивной. Рекурсия может быть прямой и косвенной: прямая — когда функция вызывает саму себя явно; косвенная — когда функция вызывает саму себя через другую функцию [3]. [2]

Эталон: Рекурсивная функция — функция, которая вызывает сама себя (прямо или через другие функции). Рекурсия бывает прямой и косвенной; каждый шаг сводит задачу к такой же задаче меньшего размера, пока не будет достигнут случай без рекурсии (например, факториал при n = 0 или 1).

**Q10. Какими способами преобразуют чертёж в начертательной геометрии, чтобы получить истинную величину фигуры?**

Ответ (ok): Чертёж в начертательной геометрии преобразуют следующими способами, чтобы получить истинную величину фигуры:

1. Способом плоскопараллельного перемещения — при этом плоскую фигуру преобразуют в плоскость уровня, а затем — в проецирующую прямую, при этом фронтальные проекции остаются конгруэнтными, а горизонтальные проекции перемещаются по прямой, параллельной оси х [1].  

2. Способом замены плоскостей проекций — заменяют одну из плоскостей проекций на новую, перпендикулярную неизменяемой, и на неё проектируют фигуру, что позволяет определить истинную величину плоской фигуры [3].  

3. Способом вращения вокруг проецирующей прямой — при этом фигура вращается вокруг прямой, лежащей в плоскости и перпендикулярной к плоскостям проекций, что позволяет получить истинную величину [5].

Таким образом, для определения истинной величины плоской фигуры применяются способы плоскопараллельного перемещения, замены плоскостей проекций и вращения вокруг проецирующей прямой [5].

Эталон: Используют способ замены плоскостей проекций (фигура неподвижна, меняется одна из плоскостей проекций) и способ плоскопараллельного перемещения, частный случай которого — вращение вокруг проецирующей прямой (плоскости проекций неизменны, перемещается фигура).
